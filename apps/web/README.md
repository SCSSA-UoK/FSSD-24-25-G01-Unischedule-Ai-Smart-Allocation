# Next.js web app

Member 1 initializes Next.js App Router/TypeScript/Tailwind here, with a common layout, login and API client.

Each member develops feature-specific pages and components in the assigned folders.

- Member 1: `(dashboard)/timetable`, `(dashboard)/imports`, `(dashboard)/scenarios`, `(dashboard)/ai-investigations`
- Member 2: `(dashboard)/allocation`
- Member 3: `(dashboard)/facilities`
- Member 4: `(dashboard)/operations`

Shared components and API clients go under `src/components/` and `src/lib/`.
