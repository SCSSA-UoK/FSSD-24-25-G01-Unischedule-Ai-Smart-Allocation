# Shared OpenAPI contracts

Each member publishes an OpenAPI YAML/JSON specification for their service:

- `platform.openapi.yaml` — Member 1
- `agent.openapi.yaml` — Member 1
- `allocation.openapi.yaml` — Member 2
- `facilities.openapi.yaml` — Member 3
- `operations.openapi.yaml` — Member 4

The placeholders are not real API specifications yet. Agree on schemas and sample requests before frontend and AI-tool integration. Spring Boot and FastAPI can generate OpenAPI documentation from code once implemented.
